# Karmany Monsta Android

Videojuego Android del universo Karmany Monsta. Bloques 01 y 02 validados en Preview 3 y 4. Bloque 03 configura Libro, estructura de equipo y entrenadores; combate y captura jugable pendientes de fichas y reglas de intervención del entrenador.

Ramas previstas: main (publicable), dev/karmany-core (baseline validado), feature/* (trabajo pendiente de validación).

## Probar desde Android

Descargar el APK de la preview más reciente en [Releases](https://github.com/axenoban/karmany-monsta-android/releases). Seguir [Prueba Android 01](docs/PRUEBA_ANDROID_01.md). Cada entrega permite instalación y actualización sobre la preview anterior.
